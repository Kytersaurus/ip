# SE-EDU Git standard

Use this skill whenever creating, reviewing, or proposing a commit or branch in this project. Follow https://se-education.org/guides/conventions/git.html.

## Commits

- Write a meaningful subject in imperative mood, capitalize its first letter, omit the final period, and keep it under 50 characters when practical (72 characters maximum).
- Add a body for non-trivial commits. Separate it from the subject with a blank line, wrap it at 72 characters, and use blank lines between paragraphs.
- Explain what changed and why it changed, using present tense for the situation and imperative mood for the change. Do not explain implementation details that the diff already shows.
- Use a scope or category prefix only when it improves clarity.

## Branches

- Use meaningful kebab-case names.
- For issue-related branches, use `<issue-number>-<keywords-from-issue-title>`.
